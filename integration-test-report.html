发现并修复的问题

[P0] 登录响应缺少 role_codes 字段
前端 authStore.ts 的 hasRole() 和 hasPermission() 方法依赖 user.role_codes 数组进行权限判断， 但后端 /auth/login 返回的 user 对象未包含此字段，导致 TypeError: Cannot read properties of undefined (reading 'includes') 错误， 受保护路由全部无法访问。
修复：在 auth.py 登录接口中构建 user_response 字典，显式添加 role_codes 字段（从 rbac_engine.get_user_roles() 提取）。 同时更新 UserInfoResponse 模型和 /auth/me 端点以保持一致性。
[P1] 端口 8000 被僵死进程占用
先前运行的 uvicorn 进程（PID 33324）被终止后，TCP 端口 8000 仍显示为 LISTEN 状态但进程已不存在， 导致新服务器无法绑定该端口。
修复：将后端迁移至端口 8002，同步更新 vite.config.ts 中的代理目标地址为 http://localhost:8002。
[P2] StatusBadge 组件缺少 accent 变体
前端 StatusBadge 组件的 BadgeVariant 类型未定义 accent 变体， 导致 TypeScript 编译错误。
修复：在 components/ui/index.tsx 中为 BadgeVariant 类型添加 accent 选项，并在 badgeStyles 和 dotStyles 中添加对应样式。
